# Dukaan Payouts Dashboard

A clean, responsive **static dashboard website** built using **React** and **Tailwind CSS**. This project helped me practice Tailwind utility classes, responsive design, and mobile navigation using a hamburger menu.

## 🚀 Features
- Fully responsive layout
- Tailwind CSS-based design
- Hamburger menu for small screens
- Clean and modern UI
- Static website (no backend)

## 🖥️ How to Run Locally
```bash
git clone https://github.com/tushar0i/dukaan-payouts-dashboard
cd dukaan-payouts-dashboard
```

You can use **npm**, **yarn**, or **pnpm**.

### **Using npm**
```bash
npm install
npm run dev
```

### **Using yarn**
```bash
yarn install
yarn dev
```

### **Using pnpm**
```bash
pnpm install
pnpm dev
```
